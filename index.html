Android

Download for Android

Version 1.0.27 · APK installation file

Get started

  1. Download the app, then open the downloaded file.
  2. If prompted, allow your browser to install apps from this source. Return and choose Install.
  3. Open Xtra Radio and tap Play.
How updates work

When an update is available, open Xtra Radio and tap Update. The first time, Android may ask you to allow Xtra Radio to install updates. Return to the app and follow the installation prompts. Keep your existing app installed.

Windows

For Windows 10 and 11 computers with an Intel or AMD 64-bit processor.

Download for Windows

Version 1.0.34 · Windows setup file

Get started

  1. Download and open Xtra-Radio-Setup.exe.
  2. Follow the setup prompts to install Xtra Radio.
  3. Open Xtra Radio from your desktop icon or Start menu and press Play.
Windows security prompts

This direct-download installer is not digitally signed. Windows or your browser may show an unfamiliar-app warning. If a warning appears and you are unsure, stop and ask the person who supplied this download link for help.

How updates work

When an update is offered in Xtra Radio, select Update and follow the setup prompts. The app closes during installation. Keep your existing app installed.
